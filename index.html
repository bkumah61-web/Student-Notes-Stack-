Student Lecture Notes Management System

Record lectures, organize course notes and manage them using a stack.

! Why Is a Stack Important in This Application?

A stack organizes lecture records so the most recently added lecture is accessed first. It follows LIFO: Last In, First Out.

  1. push(): Adds a new lecture note to the top of the stack.
  2. pop(): Removes the lecture note currently at the top.
  3. top(): Shows the most recent lecture without removing it.
  4. empty(): Checks whether the stack has any lecture notes.
  5. Order: Helps students quickly access the latest lecture they recorded.
  6. Organization: Keeps lecture records together with their course details.
Example: If you record Database Systems first and Computer Networking next, Computer Networking becomes the top item. Calling pop() removes Computer Networking first.

Limitation: A stack is best when the latest lecture is the one you need to access first. Searching for older lectures is also provided in this app for convenience.
